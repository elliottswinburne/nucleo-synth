# Synthesizer

A synthesizer running on a [NUCLEO-F446RE](https://www.st.com/en/evaluation-tools/nucleo-f446re.html). The board generates audio and streams it
over the ST-LINK virtual COM port. Python script on the PC plays it and shows
a scope view.

## Layout

| Path        | Contents                                                        |
|-------------|-----------------------------------------------------------------|
| `firmware/` | STM32CubeMX project (`synthesizer_1.ioc`), built with CMake     |
| `host/`     | `synth_rx.py`: receives the stream, plays it, draws the scope   |

## Serial protocol

Each frame is `0xA5 0x5A` followed by 256 little-endian int16 mono samples (514 bytes),
sent at 22050 Hz sample rate over 921600 baud.

## Firmware

Requires the Arm GNU toolchain (`arm-none-eabi-gcc`), CMake and Ninja.

```sh
cd firmware
cmake --preset Debug
cmake --build --preset Debug
```

The output is `firmware/build/Debug/synthesizer_1.elf` (and `.bin`), which can be
flashed with STM32CubeProgrammer.

The application code is in `firmware/Core/Src/synth_core.c`. The rest of `Core/` and
`Drivers/` is generated by STM32CubeMX. When regenerating from the `.ioc`, keep
edits in `main.c` inside the `USER CODE` sections.

## Host

```sh
cd host
pip install -r requirements.txt
python synth_rx.py                # auto-detects the ST-LINK port
python synth_rx.py --port COM5    # or name the port explicitly
python synth_rx.py --help         # all options
```
